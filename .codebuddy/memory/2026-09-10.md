## 历史曲线弹窗：双击注册条件排查（用户问「为什么 a.name 能弹窗、a.有钢信号 不行」）

结论：双击弹窗的注册与「绑定挂在哪个属性名下」无关，只与**有效绑定条目数是否恰好为 1**有关。

- 注册代码：`AriView/storage/index.html:390-437`（`trySetDoubleClickHandlerForNode`），各场景页同款副本在 `AriView/storage/导入后出现的html文件/*.html:327-374`
  - 条件1：`node.hasOwnProperty('_dataBindings')`
  - 条件2：遍历 `a/s/p` 三段，把 `typeof cfg.id === 'string'` 的条目收进 `allBoundings`
  - 条件3：**仅当 `allBoundings.length === 1`** 才 `node.s('onDoubleClick', ...)`；`0` 条与 `>1` 条都不注册（>1 只告警，防误触）
  - 弹窗：index.html 走 `PopupManager.show('history-trend', {tag,tagid,name})`；老场景页走 `openHistoricalDialog(bindingConfig, node._toolTip)`（`typeVar` 取对象首键值）
- 文档依据：`AriView/AriView部署包说明.md` §3.5.2（“仅当恰好 1 个有效绑定（含 cfg.id）时注册”）

## 本次核实到的关键事实（供下次直接复用，勿再全库搜索）

- 场景 JSON 图元绑定结构：`"p": { "dataBindings": { "a": { "<属性名>": { "id": "NumTag/..." , "func": ... } }, "s": { "text" / "2d.visible": {...} } } }`；节点属性值另存为同级 `"a": { ... }`
  - 例：`DaYeTeGang/中棒线轧机.json:7061-7089`（热检图标 `a.有钢信号` 单绑定，tag=`track-1-RollTable6AEntryHmd`，图元 `symbols/大冶特钢中棒/有钢信号 2.json`）
- 图元 json 里的 `dataBindings` 是**数组**（属性声明，如 `{"valueType":"String","attr":"有钢信号","defaultValue":"True"}`），不是点位绑定；点位绑定必须写在节点自己的 `p.dataBindings`
- 智能调度类场景用**节点级** `s.onDoubleClick` 函数串（`data._dataBindings.s.text.id` 硬编码路径）；DaYeTeGang 场景 JSON 里没有节点级 onDoubleClick（仅全屏那个），页面里 `trySetDoubleClickHandlerForNode` 只定义未被调用（当前发布的场景页里是死代码，双击来源待与用户确认）
- `AriView/libs/sbind.js`：遍历 `getDataBindings()` 的 `i.a`（同理 s/p），键名即写回属性名（`data.a(name,value)`），与弹窗注册无关
