## RecognitionDialog 多炉号合并显示（v1.5）
- 需求：A1/A2 任一炉先报警即弹窗，另一炉后报警应追加面板一并显示，不互相顶掉
- 实现：render 内维护 `records = { furnaceCode: 最新报警 }` 集合；update 时新指纹按炉号并入（新炉追加、已有炉替换该炉记录），refresh() 重建面板区
- 面板区 `buildPanelsHTML` 按炉逐个生成表格面板（卡号/钢坯号/跟踪炉号/炉前识别炉号），炉间 14px 间隙；单炉 460px、双炉 780px
- 基本信息行显示炉号集合（A1、A2）+ 最新报警时间；close 时遍历 records 各炉分别存 localStorage 缓存
- 去重不变：指纹含 furnaceCode，同炉同钢坯同炉号重复报警忽略
- 中棒线加热炉.js 无需改动（showRecognitionDialog 每次报警都调 PopupManager.show，单例下走 update 合并）
