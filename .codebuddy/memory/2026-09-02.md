## 历史弹窗时间选择器修复：滚动条 + 向下显示问题（用户反馈）
- 根因：CSS `#custom-date-picker { top: 120px !important; }` 覆盖 JS 内联定位，自定义 picker 永远钉在 120px 向下展开；且 `position: absolute` 超出 iframe 文档高度 → 主弹窗滚动条。主路径实际是 flatpickr（`libs/flatpickr/flatpickr.min.css` 已引入，初始化成功，默认 position auto 向下展开、append body 绝对定位）。
- 修复 `AriView/custom/HistoricalDataDialog/newDataDialog.html`：
  1. 删除 `top: 120px !important`
  2. 自定义 picker `showCustomDatePicker`：`position: absolute`→`fixed`（相对 iframe 视口，不撑文档）；定位逻辑重写——优先输入框上方（`baseTop - pickerHeight - 10`），上方空间不足转下方，`Math.min` 兜底不超视口底部；新增 `.below-position` class：小三角改顶部朝上 + `fadeInBottom` 动画
  3. flatpickr 配置：加 `position: "above"`（默认上方）、`disableMobile: true`、`onOpen` 回调把日历改为 `position: fixed` 并按输入框 rect 校准位置（上方优先，不足转下方，clamp 在视口内，`margin: 0`）
- 经验：flatpickr open 时先 calcPosition 再触发 onOpen，onOpen 内改 fixed+top/left 可覆盖定位；window resize 时 flatpickr 会重新定位还原 absolute（小概率，忽略）。
